# まちの政治台帳

全国の自治体から、首長・議員・次回選挙の情報を出典と資料時点でたどる公開サイトです。

## 収録範囲

- 全国1,741市区町村：自治体コード、都道府県、自治体公式サイト、首長氏名。首長名簿は **2025年4月30日現在** の記録で、最新の在職は保証しません。
- 文京区：39人（現職首長1人、区議33人、元職・新人5人）、270件の職歴・学歴、PTA・地域活動、団体役職、政党・政策団体、政策・議会活動の記録。
- 文京区の次回選挙：25人の本人表明・公認・支援発表・第三者情報サイト掲載等を区別。現職の次回出馬を自動では推定しません。
- その他の自治体の議員、経歴、政策成果、予定者の詳細は未収録です。都道府県知事・都道府県議会と政令市の行政区は対象外です。

## 公開

GitHub Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定してください。`Update sources and publish` ワークフローが `dist` をGitHub Pagesへ公開します。

初回設定後の公開先は通常 `https://nobby11334.github.io/Localpoliticians/` です。実際のURLと公開の成功はActionsの `Deploy` ステップとPages画面で確認してください。

`main` へのpush、手動実行、毎日22:00 UTC（翌朝7:00 JST）に実行します。定期・手動実行は公開資料の本文変更を取得し、取得成功・失敗・変更履歴を `data/status.json` に保存して公開します。失敗時は以前の成功ハッシュを維持します。変更は確認待ちであり、人物の所属・経歴・実績・出馬を自動で書き換えません。全国名簿そのものは出典と氏名を再検証して更新してください。

## ローカル作業

Node.js 22とPython 3.12（標準ライブラリのみの監視処理）を使用します。

```sh
npm run build
npm test
python scripts/update.py
npm run build
```

- `web/`：全国検索画面、文京区詳細台帳のテンプレート
- `data/national.json`：自治体・首長の資料時点記録
- `data/bunkyo.json`：出典付き人物情報と監視対象
- `data/status.json`：資料確認の永続履歴
- `scripts/build.mjs`：静的サイト生成。プロジェクト配下の相対URLで動作
- `dist/`：公開成果物

全国データの出典・変換方法は [data/SOURCES.md](data/SOURCES.md) を参照してください。自治体URLはCode for Fukuiのlocalgovjp（CC0）を利用。首長氏名は地方自治総合研究所の名簿と同研究所の選挙結果資料で照合しています。元資料の著作物全体を再配布するものではありません。

## 訂正・拡充

画面の追加・訂正ボタンからGitHub Issuesの下書き画面へ移動します。送信は利用者が内容を確認して行います。対象人物、自治体コード、出典URL、資料基準日、変更内容を添えてください。本文変更の検出だけで実績を認定しません。

旧私用サイトの認証情報・保存API・編集権限は公開版に含めていません。公開版には匿名でデータを書き換えるAPIはありません。
