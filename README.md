# まちの政治台帳

全国の自治体から、首長・議員・次回選挙の情報を出典と資料時点でたどる公開サイトです。

## 収録範囲（2026-11-04調査）

- 全国1,741市区町村を検索。首長の全国基礎名簿は **2025年4月30日現在** の記録。
- **47都道府県・1,411自治体に人物情報、7,878件の人物レコード、25,339件の経歴・所属・役職・政策等の記録**を収録。
- 議員等の名簿レコード7,114人、首長の詳しい記録52人、次回選挙の表明・公認・推薦・掲載等843人。職歴・学歴・議員歴を収録した人物レコード3,586件。区分は重複します。
- 文京区の39人・285件の詳しい比較台帳も継続。高山泰三氏の国民民主党公認を党公式発表で追加確認。
- 議会の全員名簿と、政党が公開する当該党の所属名簿を区別。政党勢力や議会定数を示す件数ではありません。会派から党籍を推定しません。
- 名簿・プロフィールは資料掲載時点の情報であり、閲覧時点の在職・役職継続は保証しません。掲載日不明は取得日と分けて表示。次回選挙の予定者は正式届出済みと扱いません。
- 同一人物のひらがな・漢字・通称表記が根拠不足で別レコードになる場合があります。件数は厳密な実人数ではありません。
- 都道府県知事・都道府県議会と政令市の行政区は現在の自治体区分の対象外。個々人の全経歴・全活動・全政策成果の網羅調査ではありません。

自治体別に「議員・経歴」「次回選挙の発表等」「職歴・地域活動」を開き、氏名・政党・会派・経歴で検索、最大4人の出典付き比較ができます。全国の人物名でも自治体を探せます。首長は別の枠で表示します。

## 公開

GitHub Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定してください。`Update sources and publish` ワークフローが `dist` をGitHub Pagesへ公開します。

初回設定後の公開先は通常 `https://nobby11334.github.io/Localpoliticians/` です。実際のURLと公開の成功はActionsの `Deploy` ステップとPages画面で確認してください。

`main` へのpush、手動実行、毎日22:00 UTC（翌朝7:00 JST）に実行します。定期・手動実行は登録した名簿・発表等のHTML本文およびPDF/XLSXファイルの変更を取得し、取得成功・失敗・変更履歴を `data/status.json` に保存して公開します。失敗時は以前の成功ハッシュを維持します。変更は確認待ちであり、人物の所属・経歴・実績・出馬を自動で書き換えません。全国名簿そのものは出典と氏名を再検証して更新してください。

## ローカル作業

Node.js 22とPython 3.12（標準ライブラリのみの監視処理）を使用します。

```sh
npm run build
npm test
python scripts/update.py
npm run build
```

- `web/`：全国検索画面、文京区詳細台帳のテンプレート
- `data/national.json`：自治体・首長の資料時点記録
- `data/bunkyo.json`：出典付き人物情報と監視対象
- `data/status.json`：資料確認の永続履歴
- `data/imports/`：出典を確認した全国調査データ
- `data/enrichment/`：全掲載人物の追加調査・出典・本人照合根拠・取得履歴（JSON.gz、ビルド時展開）
- `data/coverage.json`：収録自治体・件数・人物名検索索引
- `data/regions/`：ビルド時に生成する自治体別データ（Git対象外）
- `scripts/merge-expanded.py`：出典・氏名・自治体コードを統合
- `tools/research/`：再取得・抽出スクリプトと調査報告
- `scripts/build.mjs`：静的サイト生成。プロジェクト配下の相対URLで動作
- `dist/`：公開成果物

全国データの出典・変換方法は [data/SOURCES.md](data/SOURCES.md) を参照してください。自治体URLはCode for Fukuiのlocalgovjp（CC0）を利用。首長氏名は地方自治総合研究所の名簿と同研究所の選挙結果資料で照合しています。元資料の著作物全体を再配布するものではありません。

## 訂正・拡充

画面の追加・訂正ボタンからGitHub Issuesの下書き画面へ移動します。送信は利用者が内容を確認して行います。対象人物、自治体コード、出典URL、資料基準日、変更内容を添えてください。本文変更の検出だけで実績を認定しません。

旧私用サイトの認証情報・保存API・編集権限は公開版に含めていません。公開版には匿名でデータを書き換えるAPIはありません。
