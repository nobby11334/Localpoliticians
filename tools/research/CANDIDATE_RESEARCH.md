# 2027年次回選挙予定者データの再取得・抽出

2026年11月4日調査。スナップショットは836人、181自治体、26都道府県、経歴等938件。全国網羅ではない。正式届出前の公認・推薦・政党予定者を収録し、過去選挙の候補者名簿から次回出馬を推定していない。

## 実行

Python 3.10以降と `pdfplumber`、`lxml` が必要。全国自治体レジストリの `municipalities[].code/name/pref` を利用する。

```sh
python expanded/rebuild_candidates.py \
  --registry data/national.json \
  --output /tmp/rebuilt-candidates.json
```

既存データを直接更新せず、再取得結果を別ファイルに出力して変更内容を確認する。再取得で候補者数やページ構造が変わる場合がある。`--as-of YYYY-MM-DD` は実際に取得した日のみ指定する。

このスクリプトは下記公式資料を一時ディレクトリへ取得する。立憲は2027年公式一覧から市区町村選挙ページを最大10並列で取得する。個別ページの取得失敗があれば出力を確定せずエラーとする。生のPDF・HTMLは成果物に含めない。

## 除外と表記上の制約

- 維新の府県議予定者77人と、公明福岡の県議予定者は除外。府県議選挙区を一つの市町村へ割り当てない。政令市議は親市の5桁コードに対応し、区名は候補注記に保持。
- 自治体名が複数県で重複する場合は県名で照合する。維新の府中市・特別区は当該公式一覧の東京部分。照合できない自治体名は追加しない。
- 自民PDFで氏名欄の文字を抽出できない一部の人は、PDF内の読み仮名で表示し注記する。漢字名を推定補完しない。
- 推薦を受けた人の党籍は推定しない。「党籍未確認（○○党推薦）」とする。
- 公認決定日が資料にない場合 `announcedAt` は「不明」。一覧の確認日・基準日を決定日に転用しない。
- 共産党の石沢のりゆきは2027党ページ掲載を確認したが、公認の明示がないため「政党予定者掲載」とする。
- 職歴・学歴は資料記載の範囲のみ。現職表示も資料時点であり、その後の辞職・異動等を独立に確認したものではない。職業記載に就業期間がない場合は期間未確認とする。
- 姓名の漢字と通称が異なる例がある。既存人物への統合時は別途照合する。文京区では田中利周＝田中としかね、市村泰敏＝市村やすとし、佐藤豪一＝豪一、山田浩子＝山田ひろこ、浅川昇＝浅川のぼる、野口健太郎＝のぐちけんたろう。

## 検証

元の抽出処理では公式資料を実取得し、全コード存在、氏名・出典の非空、自治体コード＋氏名の重複ゼロを確認。パッケージ化した各抽出スクリプトは、取得済み原資料を使って再実行し、自治体コード＋氏名で並べ替えた元スナップショットと全836レコードの内容一致を確認した。スナップショットの件数・SHA-256は `candidates-research-report.json` にある。

公式ページは随時変更されるため、将来の再取得で836人の完全一致は保証されない。恒久的な自動更新として扱う前に差分を人が確認する。
