全人物の出典は行政・議会公式HTML。会派を政党に推定変換しない。私的連絡先・住所・生年月日・家族情報はJSONに出力していない。会派と政党の独立掲載がある姫路市・松本市は両方保持。

資料の「現在」日があれば `asOf` に採用。無ければページ更新日、いずれも無ければ掲載確認日。区別は `asOfBasis` に明記。したがって2026-11-04時点の現職保証ではない。大阪市は各会派ページをそれぞれ出典として保持。

西宮市公式名簿は繰り返しHTTP503のため未収録（sourcesに取得エラーを記録）。一部のリンク先プロフィールも取得できなかったため、未取得を不明として扱う。

再取得手順（Python 3 + lxml）:

```bash
python collect-council-central.py --refresh
python enrich-central.py
```

`fetch-central.py` は名簿ソースURL設定と構造確認を保持する依存ファイル。`enrich-central.py --cached-only` は取得済みプロフィールHTMLだけを再利用する。HTMLの構造変更・名簿人数変化時は、出力を確認してから取り込むこと。再実行は既存JSONを置換する。個人連絡先を含む原文HTMLは調査用キャッシュであり公開データへ同梱しない。
