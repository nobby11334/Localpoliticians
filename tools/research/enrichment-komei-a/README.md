# 公明党掲載者A群・1321人の個別情報調査

入力は `komei-a.json`。元のID・自治体コード・氏名を保持し、結果の `findings` は今回確認できた追加事実だけを含む。元のfindingsは統合側で保持する。

## 取得と本人照合

1. 入力の本人HPまたは政党の個人プロフィールを取得する。既存cacheはサイズ0を未取得として再取得する。
2. `/member/detail/` は党の個人プロフィールとして扱い、本人名を照合した上で「公式ホームページ」等の明示リンクを追跡する。党共通の「党プロフィール」「公明党の政策」メニューを本人の略歴や政策に帰属させない。
3. 本人HPのプロフィール・略歴・政策等へのリンクを確認し、本人配下のページだけを取得する。共有 `komei.or.jp/km/` では本人のパス配下を条件とする。
4. 各ページで入力名または入力に含まれる氏名表記を照合。取得だけできても本人一致が確認できないページからは追加しない。
5. `audit_komei_a.py` でキャッシュを再解析し、本人HPと公式リンクの対応、根拠見出し、単一本文範囲を監査する。トップページの情報は「プロフィール」「略歴」等の明示見出しで囲まれた小さい本人紹介欄のみを対象とする。

最大8並列、同一ホストは2並列。HTTPセッションを再利用し、総タイムアウト18秒、読み出し9秒、再試行は最大1回。401/403/404/410等は同じリクエストを繰り返さない。取得失敗・空本文・本人不一致を区別する。HTTPからHTTPSへの正規化を行う。

## 抽出範囲

本人プロフィールの学歴・職歴・資格・議員歴・PTA等の地域活動・団体役職、本人が示した政策の短い事実文を対象とする。政策だけのページから職歴を推定しない。長文の丸写しを避け、学歴や役職等の事実は短く収録する。出典の現職・役職が現在も継続しているとは推定しない。

住所、電話、メール、生年月日、家族、趣味等は収録しない。引用人物・家族・知人等の経歴、称賛表現、長い文章、学校や会社を特定できない「同校」「同社」だけの断片は追加しない。プロフィールが画像だけの場合や本文取得・照合ができない場合、経歴が存在しないとは判断しない。

各追加findingの `evidence` は、入力氏名の `matchedName`、実際の根拠見出しまたはページ題 `sectionHeading`、対象本文のXPath `selector`、抽出条件 `rule`、発見したリンクの文言等を保持する。実ページで照合した氏名表記が異なる場合は `observedMatchedName` に保持する。

## ステータス

- 情報追加：今回の根拠付き事実を追加。
- 既存内容確認：公開ページの取得と本人同定を確認したが、今回の追加対象となる事実がない。元の全経歴を再検証したという意味ではない。
- 追加根拠未確認：公開ページは取得できたが、本人一致等の追加条件を満たす根拠を確認できない。
- 取得失敗：取得できず追加判断ができない。

全員に取得試行結果を付与する。追加がなくても「経歴なし」「活動なし」と評価しない。

## 再実行

Python 3.10以降、`aiohttp`、`lxml` を使用する。入力・スクリプトを同じディレクトリに置く。

```sh
python enrich_komei_a.py
python recover_komei_a_timeouts.py
python recover_komei_a_aliases.py
python audit_komei_a.py
```

取得途中の部分JSONから再開できる。再調査する場合は過去の部分JSONを別名に退避してから実行する。キャッシュはHTML等の原資料を含むローカル作業用であり、公開対象に含めない。

入出力等は環境変数 `KOMEI_A_INPUT`、`KOMEI_A_OUTPUT`、`KOMEI_A_CACHE`、`KOMEI_A_SOURCE_CACHE` で変更可能。確認日は `KOMEI_A_CHECKED_AT`（この調査の既定値は2026-11-05）で指定する。将来の再調査では実際の確認日を明示し、過去キャッシュを新規取得と混同しない。

読み仮名による表記照合を補完する場合も、当該本人の党公式個人プロフィールh1で確認できる姓名・ふりがなだけを用いる。読み方を辞書や推測で補完せず、同じh1から確認した混在表記のみを照合する。根拠URLは `identitySources` に残す。

`komei-a-verified-supplement.json` は共有記事の本人カードから個別ページへ移動して確認した補足事実。生本文の複製ではなく、当該本人の経歴欄等を短く要約したレコードのみを保存する。

## 検証済みスナップショット

2026-11-05調査の最終版は1321人全員を保持し、868人へ7201件を追加。入力のID・氏名・自治体コードとの一致、全findingの本人照合名と根拠見出し、本文範囲、私的情報パターンの残存ゼロを確認した。

Timeoutとなった108 URLは新規HTTPクライアントで再取得したが成功0件。代表2 URLは通常のurllibでも取得できなかった。56人の表記不一致について党公式のふりがなを照合し、39人を裏付けのある表記で再処理した。未確認情報を経歴の不存在に置き換えていない。

検証を再実行する場合は、各調査・監査処理後に `python validate_komei_a.py` を実行する。レポートには入力と出力のSHA-256を保存する。

公開用パッケージは本ディレクトリのスクリプトと短い補足事実JSONのみ。入力の `komei-a.json` は別途必要。HTMLキャッシュ、旧段階の部分出力、進捗ログは含めない。
